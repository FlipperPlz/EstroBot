# EstroBot

A Discord bot for tracking HRT schedules, providing reminders, and estimating levels.

## Features
- **Flexible Administration**: Supports Oral, Injection, and Transdermal methods.
- **Natural Time Parsing**: Setup pill schedules with natural formats like `12pm` or `8:30am`.
- **Level Estimation**: Estimates peak and trough levels for common injection esters.
- **Custom Reminders**: Set daily reminders for medications or other tasks.

## Commands
- `/setup`: Create or edit your HRT profile.
- `/stats`: View your current profile, estimated levels, and next scheduled dose.
